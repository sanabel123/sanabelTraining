    HTML, CSS & JavaScript

    The web platform is built on three complementary technologies. Each has a distinct job, and together they form every page you browse.

    HTML

    HTML

    HTML (HyperText Markup Language) provides the structure of a page: headings, paragraphs, links, images, and forms. It gives the browser a document to render and gives assistive tools something meaningful to read.

    CSS

    CSS

    CSS (Cascading Style Sheets) controls presentation: layout, color, spacing, typography, and responsiveness. It lets the same HTML adapt to different screen sizes and themes without changing the markup.

    JavaScript

    JS

    JavaScript adds behavior. It runs in the browser to respond to user interaction, update the page without a reload, fetch data from a server, and tie HTML and CSS together into an interactive experience.

    How they work together

    A browser parses HTML into the DOM, applies CSS rules to determine how each element looks, and runs JavaScript to modify both the DOM and the styles over time. Changing text, hiding an element, or reacting to click all rely on this pipeline.

    This separation of concerns - structure, presentation, and behavior - is why the same three technologies still power everything from simple static pages to complex single-page applications today.
